# 第一阶段计划实施进度

## 需求追踪

### AI 自然语言生成动画脚本

- [x] 将自然语言描述解析为结构化场景对象和动作。
- [x] 根据结构化场景生成可运行的 ManimGL `Scene` 源码。
- [x] 支持基础图形、文字、函数图像、颜色、位置和常用动画。
- [x] 支持内接、百分比重叠、自动相切、圆环居中和组合图形整体变换。
- [x] 支持不规则三角形、三边长度输入、三棱锥与四棱锥立体场景。
- [x] 支持 OpenAI 兼容的大模型服务。
- [x] 大模型不可用时自动回退到本地规则。
- [x] 大模型生成代码验证失败后，携带错误信息自动修复一次。
- [x] 对模型输出实施导入、危险调用和特殊属性访问限制。
- [ ] 继续扩展复杂组合图形、三维场景和多步骤教学动画模板。

### PySide6 图形化操作界面

- [x] 动画描述输入和 Python 源码编辑。
- [x] Python 语法高亮、文件打开和源码导出。
- [x] 场景类识别与选择。
- [x] 实时预览、最终帧保存和 MP4 导出。

- [x] API 密钥只保存在当前进程内存，不写入设置文件。

## 验证方式

在项目根目录激活虚拟环境后运行：

```powershell
python -m unittest tests.test_ai_plugins tests.test_gui_workflow -v
```

手工启动桌面助手：

```powershell
python run_gui.py
```

更完整的安装、模型配置和操作说明见 [assistant_gui.md](assistant_gui.md)。
